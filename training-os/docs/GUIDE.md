# Guide utilisateur & FAQ

## Parcours administrateur (§46)

1. **Paramètres → Centre** : nom, logo, coordonnées, signataire des certificats, règles de relance.
2. **Paramètres → Formateurs** : ajouter les formateurs (cocher « Créer son accès » pour leur envoyer une invitation).
3. **Formations → Nouvelle formation** : prix, durée, conditions de certification, pondération de la progression ; puis ajouter les **modules**.
4. **Sessions → Nouvelle session** : dates, jours de cours et horaires → les séances sont générées automatiquement.
5. **Étudiants** : créer une fiche, ou **Paramètres → Import Excel** pour reprendre vos fichiers.
6. **Inscrire** (depuis la fiche étudiant ou la session) : prix, remise, nombre de versements → échéancier automatique.
7. **Paiements** : sur l'inscription, « Enregistrer un paiement » → solde recalculé, reçu par email à l'étudiant.
8. **Présences** : choisir la session et la séance → Présent / Retard / Absent / Excusé.
9. **Évaluations** : créer l'évaluation (quiz en ligne facultatif) → saisir les notes.
10. **Certificats** : les étudiants éligibles apparaissent automatiquement → « Générer ».
11. **Assistant IA** : « Qu'est-ce que je dois faire aujourd'hui ? »

## FAQ

**Un étudiant n'arrive pas à se connecter.** Vérifiez qu'il a un accès (fiche étudiant → « Créer l'accès étudiant ») ; il peut utiliser « Mot de passe oublié ». Après 5 échecs, le compte est verrouillé 15 minutes.

**J'ai saisi un mauvais paiement.** Un paiement ne se modifie pas : l'administrateur l'**annule** avec un motif (conservé dans l'historique), puis le ressaisit correctement.

**Pourquoi un étudiant est « à suivre » ?** C'est une **alerte fondée sur des indicateurs** (absences consécutives, présence faible, notes, inactivité, retard de paiement), pas un diagnostic. Les indicateurs exacts sont affichés.

**L'assistant IA dit ne pas disposer d'une information.** Il ne répond qu'à partir des données enregistrées dans TRAINING OS ; il n'invente jamais de chiffres.

**Comment vérifier un certificat ?** Scanner le QR code ou saisir la référence sur `/verify`.

**Comment exporter mes données ?** Rapports → Exports (Excel ou CSV) ; « Imprimer / PDF » sur chaque rapport.
